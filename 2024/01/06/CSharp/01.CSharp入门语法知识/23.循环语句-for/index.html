    23.循环语句-for

    23.1 知识点

    for循环语法

    for循环是一种常见的循环结构，通过初始表达式、条件表达式和增量表达式来控制循环的执行次数。

    语法结构

    for( /*初始表达式*/; /*条件表达式*/; /*增量表达式*/ )
{
    //循环代码逻辑;
}
// 第一个空（初始表达式）： 一般声明一个临时变量，用来计数用 
// 第二个空（条件表达式）： 表明进入循环的条件，一个bool类型的结果（bool变量、条件运算符、逻辑运算符、算术运算符） 
// 第三个空（增量表达式）： 用第一个空中的变量进行自增减运算

    示例

    示例一
    // 第一次进入循环时才会调用第一个空中的代码
// 每次进入循环之前都会判断第二个空中的条件，满足才会进入循环逻辑
for( int i = 0; i < 5; i++ )
{
    Console.WriteLine(i);//0 1 2 3 4
    //执行完循环语句块中的逻辑后
    //最后执行第三个空中的代码
}
    示例二
    for( int i = 5; i >= 0; i-- )
{
    Console.WriteLine(i);//5 4 3 2 1 0
}
    示例三
    //每个空位可以按照规则进行书写
//第一个空位就是声明变量，所以可以连续声明
//第二个空位就是进入条件，只要是bool结果的表达式都可以
//第三个空位就是执行一次循环逻辑过后要做的事情，做啥都行
for (int i = 0, j = 0; i < 10 && j < 0; ++i, j = j + 1)
{
}

    嵌套使用

    for循环可以与其他控制流结构（如if、switch、while、do-while）相互嵌套使用，根据实际需求进行选择。

    for (int i = 0; i < 10; i++)
{
    for (int j = 0; j < 10; j++)
    {
        Console.WriteLine(i + "_" + j);
    }
    while (true)
    {
    }
    if (true)
    {
    }
    do
    {
    } while (true);
}

    特殊写法

    for循环的三个表达式中，任何一个都可以省略，具有一些特殊写法。

    死循环

    // for循环可以写死循环
for (; ; )
{
    Console.WriteLine("for循环的死循环");
}

    代替第一和第三个空的写法

    int k = 0;
for (; k < 10;)
{
    ++k;//k++, k += 1;
}

    代替第二个空的写法

    for (k = 0; ; ++k)
{
    if (k >= 10)
    {
        break;
    }
}

    对比while循环

    for循环和while循环可以相互转换，但for循环在可以准确得到一个范围内的所有数时更为清晰。

    // for循环能实现的while循环一定也能实现，反之亦然
// for循环一般用来可以准确得到一个范围中的所有数
for (int i = 0; i < 10; ++i)
{
}

// while循环也能实现，但不如for循环清晰
int o = 0;
while (o < 10)
{
    //......................
    ++o;
}

                    Console.Write(" ");
                }

                //打印星号的列
                for (int j = 1; j <= 2*i-1; j++)
                {
                    Console.Write("*");
                }
                Console.WriteLine();
            }

            #endregion

        }
    }
